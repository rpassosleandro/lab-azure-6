# lab-azure-6
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO

# Language Studio
Analisador de linguagem natural que analisa o sentimento, frases e palavras chave, idioma predominante e entidades.
Podemos inserir perguntas e respostas, inserir documentos.
Ajuda na interpretação de textos
Criar um recurso de idioma no AI Machine Learning

# Serviço de Bot
Vai ser tão mais eficiente quanto maior for a base de dados do treinamento
Chat, ligação ou email.
As respostas são geradas a partir das palavras chave
O modelo deve ser restestado para saber se todas opções que o usuário precisa estão contempladas

# Linguagem Coloquial
Linguagem do dia a dia
Declaração: Enunciado --> Entidade --> Intenção
Passar ordens de forma simples não formal
Usar recurso de fala para texto do Serviço de Fala e de conversão de texto para fala

# Speech Studio
Transcreve um arquivo de texto para áudio ou um arquivo de áudio para texto
Tem que escolher o idioma do áudio
Pode ser criado um call center, lengendas em filmes e séries
Transcrição com tradução em tempo real
